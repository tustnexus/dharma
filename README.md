## Installation
To install the Dharma project, follow these steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/tustnexus/dharma.git
   ```
2. Navigate to the project directory:
   ```bash
   cd dharma
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## Usage
After installing the project, you can run it using:
```bash
npm start
```
